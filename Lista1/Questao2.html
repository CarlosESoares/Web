Atividade 2 – Protocolo HTTP

1. O que é o Protocolo HTTP e como é usado na Web

O HTTP (HyperText Transfer Protocol) é o protocolo usado na World Wide Web para transferir dados entre um cliente (como um navegador) e um servidor. Ele funciona no modelo cliente-servidor: o cliente envia uma requisição e o servidor responde com uma resposta.

O HTTP é stateless, ou seja, cada requisição é independente. Ele foi criado por Tim Berners-Lee em 1991 e evoluiu para versões como HTTP/1.1, HTTP/2 e HTTP/3. O HTTPS é a versão segura com criptografia.

Diagrama do ciclo de requisição e resposta HTTP

Exemplos de Requisições

GET – Solicitar uma página

GET /index.html HTTP/1.1
Host: www.exemplo.com
User-Agent: Mozilla/5.0...
Accept: text/html

Estrutura de uma requisição HTTP

POST – Enviar dados (ex: login)

POST /login HTTP/1.1
Host: www.exemplo.com
Content-Type: application/x-www-form-urlencoded
Content-Length: 27

username=joao&password=123

2. Detalhes de um Request e Response Capturado

Captura real ao acessar http://example.com:

Request (Requisição)

GET / HTTP/1.1
Host: example.com
User-Agent: curl/7.68.0
Accept: */*
Connection: keep-alive
  • Linha inicial: GET / HTTP/1.1 → método, caminho, versão
  • Host: domínio do servidor
  • User-Agent: identifica o cliente
  • Accept: tipos de conteúdo aceitos

Response (Resposta)

HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8
Content-Length: 235
Server: nginx

<!doctype html>
<html><head><title>Example Domain</title></head>
<body><h1>Example Domain</h1>
<p>This domain is for use in illustrative examples...</p>
</body></html>
  • Linha de status: 200 OK → sucesso
  • Content-Type: tipo do conteúdo
  • Content-Length: tamanho em bytes
  • Server: software do servidor
