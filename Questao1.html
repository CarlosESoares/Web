O html é uma linguagem de estilização usada para criação de paginas web A estrutra de um html é formada por por <Nome_da_tag> </Nome_Da_Tag>

<!DOCTYPE> html </!DOCTYPE> /declaração que o documento é do tipo html
<html> lang="en" /tag que serve para dizer qual a linguagem da pagina
<head> // inicio do head
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0"> //dizendo as especificões para a abertura da pagina
< title questao1 </title>
</head> // fim da tag head
<body> // a tag body define o corpo principal do html onde começara a programar
</body> // o fim da tag body
</html> // fimk da tag html
