O que é JavaScript

Motivação

O JavaScript foi idealizado para aumentar a rapidez de resposta dos navegados já que todo e qualquer coisa que precisa ser feito em uma pagina web era feita uma solicitação para os servidores e os servidores faziam tudo o que deixava mais lento

Diferença entre execução no servidor e no navegador

Quando o código é executado no servidor, ele pode acessar recursos do servidor, como bancos de dados e arquivos do sistema. Já quando o código é executado no navegador, ele pode interagir diretamente com a página web e responder às ações do usuário em tempo real.

Conceito de sandbox no navegador

O JavaScript é executado diretamente no navegador do usuario o que da a ele acesso a tudo do computador o conceito de sandbox é uma area limitado criada para limitar o que pode ou não ser acessado pelo JavaScript

Conceitos globais

O JavaScript possui alguns conceitos globais como document que serve para acessar tudo da pagina console para acessar as ferramentas de desenvolvedor do navegador e alert para dar mensagens
